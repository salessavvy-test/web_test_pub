## Add Numbers Module

A simple Python module that adds three numbers together.

### Usage

```python
from add_numbers import add_three_numbers

result = add_three_numbers(10, 20, 30)
print(result)  # Output: 60
```

### Running the Example

```bash
python add_numbers.py
```

### Running Tests

```bash
python test_add_numbers.py
```
