## Features

### Add Three Numbers
A simple utility function to add three numbers together.

**Usage:**
```javascript
const addThreeNumbers = require('./addThreeNumbers');

const result = addThreeNumbers(5, 10, 15);
console.log(result); // Output: 30
```

**Running the example:**
```bash
node addThreeNumbers.js
```

**Running tests:**
```bash
npm test
```
