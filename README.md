## Features

### Add Three Numbers
A simple utility function to add three numbers together.

**Usage:**
```javascript
const addThreeNumbers = require('./addThreeNumbers');

const sum = addThreeNumbers(1, 2, 3);
console.log(sum); // Output: 6
```

**Running the example:**
```bash
node addThreeNumbers.js
```

**Running the tests:**
```bash
node test-addThreeNumbers.js
```
