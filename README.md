## Features

### Add Three Numbers
A simple utility function that adds three numbers together.

**Usage:**
```javascript
const addThreeNumbers = require('./addThreeNumbers');

const result = addThreeNumbers(5, 10, 15);
console.log(result); // Output: 30
```

**Example:**
Run the example file to see the function in action:
```bash
node example.js
```
